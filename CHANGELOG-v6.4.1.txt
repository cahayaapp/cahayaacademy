BELAJARISLAM.ONLINE LMS v6.4.4

PERUBAHAN UTAMA
1. Ebook kini dapat memakai dua sumber PDF:
   - Google Drive
   - Upload PDF langsung ke Firebase Realtime Database (maks. 5 MB)
2. Admin dapat menempel link Google Drive atau File ID pada form Ebook.
3. Link/ID sumber Google Drive disimpan di path privat ebookSources/{ebookId}, bukan di HTML halaman publik.
4. Peserta yang sudah memiliki akses melihat tombol Download Ebook pada LMS.
5. Tombol download Google Drive tidak membuka halaman Google Drive; unduhan dipicu melalui iframe tersembunyi dan halaman LMS tetap berada di tempatnya.
6. Sumber ebook hanya dapat dibaca admin, mentor, atau pemilik ebook yang aksesnya aktif berdasarkan Database Rules.
7. Ebook lama yang disimpan langsung di Firebase tetap kompatibel.
8. Cache/service worker dinaikkan ke v6.4.4.

CATATAN KEAMANAN
- Pada aplikasi web statis, URL/file ID yang benar-benar dipakai browser untuk mengambil file masih dapat ditemukan oleh pengguna teknis melalui DevTools Network. Ini merupakan batas browser, bukan bug LMS.
- Jika membutuhkan URL Google Drive benar-benar tidak pernah dikirim ke browser, diperlukan proxy/server backend (misalnya Cloudflare Worker atau Firebase Cloud Functions) yang mengambil file dari Drive lalu mengalirkannya ke pengguna.
- Untuk mode Google Drive tanpa backend, pastikan file Drive dapat diakses melalui link agar download dapat berjalan.
