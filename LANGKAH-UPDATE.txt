LANGKAH UPDATE IZZUDDIN ACADEMY LMS v4.0.0

1. Ganti seluruh file website lama dengan isi paket v4.0.0.
2. Di Firebase Console buka Realtime Database > Rules.
3. Ganti Rules dengan isi file database.rules.json dari paket ini, lalu Publish.
4. Pastikan Authentication > Email/Password masih aktif dan domain izzuddin.online sudah berada di Authorized domains.
5. Bila memakai GitHub Pages, unggah semua file termasuk sw.js agar cache versi lama dibersihkan.
6. Setelah deployment, lakukan hard refresh sekali pada perangkat admin dan peserta.

Pembaruan utama:
- Profil/nama/WhatsApp peserta tampil realtime di admin.
- Admin dapat melihat dan mengedit WhatsApp tanpa menghapus data profil lain.
- Tombol salin nomor rekening dan nominal pada pembayaran.
- Live Chat realtime peserta ↔ admin dengan indikator pesan belum dibaca.
- Blok teks “Verifikasi sederhana” pada halaman pembayaran dihapus.
