BELAJARISLAM.ONLINE LMS v6.4.2 — UPDATE EBOOK GOOGLE DRIVE

1. Upload seluruh isi paket v6.4.2 menggantikan versi sebelumnya.
2. Firebase Console > Realtime Database > Rules.
3. Ganti Rules dengan database.rules.json v6.4.2 lalu Publish.
4. Lakukan hard refresh sekali setelah deploy.

MEMBUAT EBOOK DARI GOOGLE DRIVE
1. Upload PDF ke Google Drive.
2. Atur file agar dapat diakses melalui link sesuai kebutuhan LMS.
3. Admin > Ebook > Buat/Edit Ebook.
4. Pada Sumber file ebook pilih Google Drive.
5. Tempel link file Drive atau File ID.
6. Isi nama file download, contoh: quranic-luck-mastery.pdf.
7. Simpan Ebook.
8. Untuk ebook berbayar, setelah pembayaran di-approve peserta memperoleh akses dan tombol Download Ebook aktif.

HASIL
- Peserta tidak diarahkan ke halaman Google Drive ketika menekan Download.
- Link Drive tidak ditulis di HTML halaman publik.
- Sumber disimpan di Firebase path privat ebookSources/{ebookId}.

BATAS TEKNIS
Browser harus mengetahui endpoint yang dipakai untuk mengunduh file. Karena itu pengguna yang sangat teknis masih dapat melihat request Google Drive melalui DevTools Network. Untuk menyembunyikan origin secara penuh diperlukan backend proxy/server.
