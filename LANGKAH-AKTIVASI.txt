CAHAYA ACADEMY — LANGKAH AKTIVASI CEPAT
=======================================

1. FIREBASE AUTHENTICATION
   Firebase Console → Security/Authentication → Get Started → Sign-in method
   → aktifkan Email/Password.

2. DATABASE RULES
   Firebase Console → Realtime Database → Rules.
   Salin seluruh isi file database.rules.json, lalu klik Publish.

3. UPLOAD KODE
   Upload seluruh isi folder ini ke repository GitHub Pages atau Firebase Hosting.
   Jangan hanya mengunggah index.html; folder css, js, dan assets juga wajib ikut.

4. AUTHORIZED DOMAIN
   Jika memakai GitHub Pages, tambahkan domain GitHub Pages pada:
   Authentication → Settings → Authorized domains.
   Contoh: username.github.io

5. AKTIFKAN ADMIN PERTAMA
   Buka alamat:
   https://alamat-lms-anda/setup.html
   Isi nama, email, dan kata sandi administrator.
   Aktivasi hanya dapat diklaim oleh satu akun pertama.

6. MASUK KE LMS
   Buka index.html atau alamat utama LMS, lalu login memakai akun admin.

7. URUTAN PENGISIAN
   a. Menu Pengguna → buat akun Pengajar dan Peserta.
   b. Menu Kelas Saya → Buat Kelas.
   c. Atur pengajar dan peserta kelas.
   d. Tambahkan Modul, Pertemuan, link YouTube, materi, tugas, dan kuis.

ALUR LIVE
Streamlabs → YouTube Live (Unlisted) → salin link video →
Kelas → Tambah Pertemuan → tempel link YouTube.
Setelah live selesai, link yang sama akan menjadi tayangan ulang.

CATATAN LOGO
File assets/logofi.png sudah tersedia sebagai logo sementara.
Ganti file tersebut dengan logo resmi pesantren menggunakan nama file yang sama.
