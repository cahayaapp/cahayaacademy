BELAJARISLAM.ONLINE LMS v5.1.0 — FULL PACKAGE

1. UPLOAD
   Upload seluruh isi folder ini ke root hosting/GitHub Pages.

2. CUSTOM DOMAIN
   File CNAME sudah berisi:
   belajarislam.online

3. FIREBASE AUTHENTICATION
   - Email/Password: Enabled
   - Authorized domains:
     belajarislam.online
     www.belajarislam.online (jika digunakan)

4. REALTIME DATABASE
   Buka Realtime Database > Rules.
   Salin seluruh isi database.rules.json lalu Publish.

5. FIREBASE STORAGE
   Aktifkan Storage jika bukti transfer memakai upload gambar.
   Salin seluruh isi storage.rules lalu Publish.

6. AKUN ADMIN
   Pastikan akun admin yang sudah ada mempunyai:
   users/{UID}/role = admin

7. PENGATURAN ADMIN
   Login admin > Pengaturan:
   - Nama bank
   - Nomor rekening
   - Nama pemilik rekening
   - WhatsApp admin
   - Penandatangan sertifikat

8. KELAS & VIDEO
   Admin > Kelola Kelas:
   - buat kelas Gratis atau Berbayar
   - tambah video YouTube atau Google Drive
   Link YouTube biasa akan dinormalisasi otomatis menjadi embed youtube-nocookie.
   Link Google Drive biasa akan dinormalisasi menjadi preview bila format ID dapat dikenali.

9. KUIS
   Admin > Kuis > pilih kelas dan video > masukkan soal + nilai lulus.

10. ALUR PESERTA
    Daftar > login > pilih kelas > belajar > kuis > forum > sertifikat.
    Untuk kelas berbayar: transfer > upload bukti > admin approve > akses aktif otomatis.

CATATAN UPGRADE
Data pengguna, kelas, pembayaran, dan chat versi sebelumnya tetap memakai jalur database yang kompatibel.
