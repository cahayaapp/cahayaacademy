BELAJARISLAM.ONLINE LMS — Paket Upgrade Kode

Urutan cepat:
1. Upload semua isi paket ini ke hosting / GitHub Pages.
2. Pastikan Authentication > Email/Password aktif.
3. Tambahkan domain baru di Firebase Authentication > Authorized domains:
   - belajarislam.online
   - www.belajarislam.online
4. Publish isi file database.rules.json ke Realtime Database > Rules.
5. Jika menggunakan upload bukti transfer, aktifkan Firebase Storage lalu publish storage.rules.
6. Pastikan ada minimal 1 akun admin di path users/{uid} dengan role: admin.

Fitur utama paket ini:
- Rebranding penuh ke belajarislam.online
- Landing page dengan daftar pelajar sendiri
- Dashboard pelajar desktop & mobile
- Katalog kelas gratis / berbayar
- Halaman video pembelajaran dengan forum diskusi per video
- Pembayaran transfer + upload bukti + approval admin
- Profil peserta sinkron ke admin
- Live chat peserta ↔ admin
- Admin panel untuk kelas, video, pembayaran, pengguna, dan pengaturan rekening

Catatan:
- Link video dapat memakai YouTube (embed / nocookie) atau Google Drive (preview/embed).
- Untuk kelas berbayar, peserta mengirim bukti transfer dari halaman kelas.
- Setelah admin menyetujui pembayaran, akses kelas akan aktif otomatis.
