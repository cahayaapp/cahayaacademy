BELAJARISLAM.ONLINE LMS v5.2.1 — FULL UI/UX OVERHAUL

1. UPLOAD
   Upload seluruh isi folder ini ke root hosting/GitHub Pages.

2. CUSTOM DOMAIN
   File CNAME sudah berisi:
   belajarislam.online

3. FIREBASE AUTHENTICATION
   - Email/Password: Enabled
   - Authorized domains:
     belajarislam.online
     www.belajarislam.online (jika digunakan)

4. REALTIME DATABASE
   Buka Realtime Database > Rules.
   Salin seluruh isi database.rules.json lalu Publish.

5. BUKTI TRANSFER — TANPA FIREBASE STORAGE
   Tidak perlu mengaktifkan Firebase Storage.
   Foto bukti transfer dikompres otomatis di browser, lalu disimpan terpisah di Realtime Database pada path paymentProofs/{paymentId}.

6. AKUN ADMIN
   Pastikan akun admin mempunyai:
   users/{UID}/role = admin

7. PENGATURAN ADMIN
   Login admin > Pengaturan:
   - Nama bank
   - Nomor rekening
   - Nama pemilik rekening
   - WhatsApp admin
   - Penandatangan sertifikat

8. KELAS & VIDEO
   Admin > Kelola Kelas:
   - buat kelas Gratis atau Berbayar
   - tambah video YouTube atau Google Drive

9. KUIS
   Admin > Kuis > pilih kelas dan video > masukkan soal + nilai lulus.

10. ALUR PESERTA
    Daftar > login > pilih kelas > belajar > forum/kuis > sertifikat.
    Untuk kelas berbayar: transfer > upload bukti > admin approve > akses aktif otomatis.

11. CACHE / FAVICON
    Service worker sudah dinaikkan ke cache v5.2.1.
    Setelah upload, lakukan hard refresh satu kali agar UI/favikon versi lama tidak tertahan browser.

DATA LAMA
Data pengguna, kelas, pembayaran, chat, progres, forum, dan kuis tetap menggunakan jalur database yang kompatibel dengan v5.1.1.

HOTFIX v5.2.1
