BELAJARISLAM.ONLINE LMS v6.4.5 — NATIVE DOWNLOAD FIX

1. Upload SELURUH isi paket v6.4.5 menggantikan versi sebelumnya.
2. Database Rules v6.4.4 tetap dapat dipakai; tidak wajib publish ulang hanya untuk update ini.
3. Deploy folder cloudflare-worker mengikuti cloudflare-worker/PASANG-GATEWAY.txt.
4. Salin URL workers.dev hasil deploy.
5. Masuk Admin > Pengaturan > Download Gateway URL > tempel URL Worker > Simpan.
6. Pastikan file ebook Google Drive adalah PDF biasa dan sharing mengizinkan akses/download.
7. Hard refresh browser sekali setelah upload paket.
8. Uji dari akun member yang status ebooknya aktif: klik Download Ebook PDF.

Tujuan v6.4.5:
- klik Download -> browser/device memulai unduhan native,
- progres unduhan muncul di download manager/bar perangkat,
- halaman member tidak membuka Google Drive,
- source Google Drive tidak lagi di-fetch langsung oleh JavaScript member.
