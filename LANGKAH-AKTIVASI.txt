BELAJARISLAM.ONLINE LMS v6.0.1 — LANGKAH UPDATE

1. Backup repository lama jika diperlukan.
2. Hapus / ganti seluruh file versi lama dengan isi paket v6.0.1. Jangan hanya mengganti index.html.
3. Pastikan file CNAME tetap berada di root repository dan berisi:
   belajarislam.online
4. Firebase Console → Authentication → Sign-in method:
   Email/Password = Enabled.
5. Firebase Console → Authentication → Settings → Authorized domains:
   tambahkan belajarislam.online
   tambahkan www.belajarislam.online hanya bila domain www juga dipakai.
6. Firebase Console → Realtime Database → Rules:
   ganti rules lama dengan isi database.rules.json versi v6.0.1 lalu Publish.
7. Firebase Storage TIDAK PERLU diaktifkan.
   - Bukti transfer: dikompresi lalu masuk ke Realtime Database pada paymentProofs.
   - Cover kelas: dikompresi/crop 16:9 lalu masuk ke Realtime Database pada classCovers.
8. Pastikan akun admin yang sudah ada memiliki:
   users/{UID}/role = "admin"
9. Upload ke GitHub Pages / hosting.
10. Setelah deploy selesai, lakukan hard refresh sekali:
    Mac: Command + Shift + R
    Windows: Ctrl + Shift + R
